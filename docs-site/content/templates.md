## What a template actually is

A template is a well-written starting prompt. Clicking **Use** fills the composer with it; it does not copy a code scaffold or create files for you. The agent still builds the app from scratch, which means you can edit the prompt before sending and nothing is pre-decided.

That is deliberate. A scaffold would lock in a structure the agent then has to work around. A prompt leaves every decision open.

## Browsing

The **Templates** page groups starters by category — marketing, productivity, finance and more — with a search field and featured picks on the home screen.

Each card shows a one-line description of the resulting app. Open one to see the full prompt before using it.

## Good templates to start from

- **Coffee subscription** — hero, roast tiers, pricing and a signup section with a warm editorial feel.
- **Kanban board** — todo / doing / done columns, quick-add cards and `localStorage` persistence.
- **Finance dashboard** — cash-flow chart, monthly budget and a filterable transaction list.
- **Personal portfolio** — an about section, selected work and contact details.

The exact set changes as templates are added. The page is the source of truth.

## Make a template your own

1. Pick the closest shape.
2. Rewrite the audience, copy and sections in the composer.
3. Send it.

> The prompt in the composer is the whole product. If the result is generic, the prompt was generic — add the specific business rules and content you actually need.

## Saving a good prompt

There is no template editor yet. Keep prompts you reuse in **Studio → Notes**, or in a text file beside the project. Notes are private and are never published.

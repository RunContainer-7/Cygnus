## Composer

| Shortcut | Action |
| --- | --- |
| `Enter` | Create the app from the home composer |
| `Shift` + `Enter` | New line without submitting |

Inside a workspace, send with the button or `Enter` depending on the composer state; `Shift` + `Enter` always adds a line.

## Command palette

| Shortcut | Action |
| --- | --- |
| `Ctrl` + `K` (Windows/Linux) | Open the workspace command palette |
| `Cmd` + `K` (macOS) | Open the workspace command palette |

The palette covers panels, modes, publish, zip export, checkpoints, notes, data, moves, and a duplicate that forks the project files as a remix without copying the chat. Type to filter, then press `Enter`.

## Search

| Shortcut | Action |
| --- | --- |
| `Ctrl`/`Cmd` + `K` | Open docs search on this site |
| `/` | Focus search on list pages that show a search field |

## Dismissing

| Shortcut | Action |
| --- | --- |
| `Esc` | Close the docs search dialog |
| `Esc` | Close an open model or mode menu |

## Browser basics that still apply

- `Ctrl`/`Cmd` + `F` searches the current page text.
- `Ctrl`/`Cmd` + `R` reloads the whole Cygnus window, not just the preview. Use the preview's own refresh control for the generated app.
- `Ctrl`/`Cmd` + `+` / `-` zooms the interface.

> Desktop menu accelerators differ from the web build. The table above is what the interface itself handles.
